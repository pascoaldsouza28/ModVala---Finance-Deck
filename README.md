# ModVala Legal Privacy Policies

Public legal pages for the ModVala Android app.

## Live pages

After GitHub Pages is enabled from the `main` branch root, the privacy policy will be available at:

https://pascoaldsouza28.github.io/ModVala-Legal-Privacy-Policies/privacy.html

## Files

- `privacy.html` - public Google Play-ready privacy policy page.
- `privacy-policy.md` - editable markdown copy of the same policy.

## Play Console note

Use the `privacy.html` GitHub Pages URL in Google Play Console. Keep this repository public so the URL is accessible without login.
