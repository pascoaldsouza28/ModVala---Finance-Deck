# ModVala Legal Privacy Policies

Public legal and compliance pages for the ModVala Android app.

Privacy policy:

Account deletion:

https://pascoaldsouza28.github.io/ModVala-Legal-Privacy-Policies/account-deletion.html

## Files

- `index.html` - public legal centre.
- `privacy.html` - Google Play-ready privacy policy page.
- `privacy-policy.md` - editable markdown copy of the same policy.
- `terms.html` - app terms of service.
- `account-deletion.html` - Google Play account deletion page.
- `community-guidelines.html` - community rules and moderation policy.
- `newsletter.html` - newsletter and promotions consent terms.
- `support.html` - support, privacy and abuse reporting contact page.
- `legal.css` - shared styling.

## Play Console note

Use the `privacy.html` URL in Google Play Console. Keep this repository public so the URL is accessible without login.
